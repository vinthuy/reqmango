🔧 B — 工程质量（6 项）

B2.1 安全加固 W4-W5 · 4天
全面安全审计 + 修复：
• SQL 注入：全量 GORM 查询 review（Raw SQL、拼接、动态 order/group）
• XSS 防护：v-html 使用审计、CSP Header 配置
• CSRF Token 中间件（SameSite cookie + double-submit）
• JWT 安全审计：过期时间(≤24h)、refresh token 轮换、签名算法
• API Key 存储加密（AES-256-GCM，当前可能明文）
• 密码策略增强（最小长度、复杂度、bcrypt cost=12）
• 敏感信息泄露检查（错误响应中不暴露 SQL/stack trace）

• N+1 查询消除：GORM Preload 审计
• API 响应分页强制（所有 list 端点含 limit/offset）
前端： • Vite bundle 分析 (rollup-plugin-visualizer) → code splitting
• 路由懒加载（已配置但需检查实际效果）
• 图片懒加载 (loading="lazy") + WebP 转换
基础设施： • PostgreSQL 连接池调优

B2.4 结构化日志系统 W5 · 2天
现状：全部使用 stdlib log.Printf（无结构、无级别、无 trace）
产出： • 替换为 zerolog（高性能结构化日志）或 slog（Go 1.21+ 标准库）
• 中间件注入 traceID（每个请求一个 UUID）
• 日志级别：debug/info/warn/error + 环境变量控制
• 敏感信息脱敏（密码、token、API key）
• 请求日志增强：method + path + status + duration + traceID + userID
• 输出到 stdout（JSON 格式，生产环境）
