🔧 B — 质量 + 生态（6 项）

B3.1 E2E 测试 (Playwright) W7 · 3天
8 个核心用户旅程：
1. 注册 → 创建 workspace → 创建 project → 创建 issue
2. Issue 生命周期：创建 → 开始 → 完成 → 关闭
3. 看板视图：拖拽列 + swimlane 切换 + card 详情
4. 周期管理：创建 sprint → 添加 issue → 燃尽图
5. 筛选栏：多条件筛选 + RQL 搜索 + 保存视图
6. AI 聊天：发送消息 → SSE 流式响应 → 创建 issue
7. 通知中心：SSE 推送接收 → 已读 → @提及
8. 页面 Wiki：创建页面 → 编辑 → 层级导航 → AI 生成
CI 集成：PR 时自动跑 E2E（或 nightly）
