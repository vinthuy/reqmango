方案 B: 组件化重写 + TDD

IssueDetail.vue 拆分为 7 个子组件，每个独立可测试

组件树

IssueDetail.vue                    ← 路由入口，编排子组件
├── IssueDetailHeader.vue          ← 顶部导航：返回 + 类型标签 + ID + 保存按钮
├── IssuePropertySidebar.vue       ← 右侧属性栏：状态/优先级/负责人/标签/日期等
├── IssueTabDetails.vue            ← Tab 1: 描述 + 自定义字段 + 评论
├── IssueTabRelations.vue          ← Tab 2: 父关系 + 子关系 + 关联关系
│   ├── RelationParentCard.vue     ←   父级卡片
│   ├── RelationSubIssuesCard.vue  ←   子工作项卡片
│   └── RelationTypeCard.vue       ←   动态关联类型卡片（可复用）
├── IssueTabAttachments.vue        ← Tab 3: 附件管理
├── IssueTabTimeTracking.vue       ← Tab 4: 工时记录
└── IssueTabActivity.vue           ← Tab 5: 活动日志

每个组件的职责 & Props/Events

Component Props Events 测试重点
