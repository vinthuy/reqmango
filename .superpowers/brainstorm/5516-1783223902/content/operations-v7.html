保存策略总结

⚡

即时保存（Instant Save）

侧边栏属性变更后立即 API 提交 — State, Priority, Assignee, Labels, Cycle, Module, Dates

📦

批量保存（Batched Save）

标题、描述、自定义字段 — 编辑后标记 dirty，点击 Save 按钮或 Ctrl+S 统一提交

📝

直接操作（Direct Action）

评论/关联/附件/工时 — 各自的增删改独立 API 调用，不经过 Save 按钮
